# 20-minute build plan

| Time | Task | Proof |
|---|---|---|
| 0-3 min | Create venv and install backend packages | terminal screenshot |
| 3-7 min | Start FastAPI and refresh AAPL | `/docs` + refresh response |
| 7-11 min | Inspect SQLite tables and chart endpoint | chart JSON |
| 11-15 min | Run SMA backtest | backtest metrics |
| 15-18 min | Start Next.js dashboard | dashboard + chart |
| 18-20 min | README, screenshots and GitHub push | repository page |

If npm install or Yahoo Finance takes longer, complete and push the API first; the dashboard can be committed as the next milestone.
